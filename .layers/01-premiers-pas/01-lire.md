## Ce que contient une étape

Une étape est un fichier Markdown. Tout le Markdown habituel s'affiche :

| Élément | Exemple |
|---|---|
| Mise en forme | **gras**, *italique*, `code` |
| Liens | [byte_layers](https://marketplace.visualstudio.com/items?itemName=byte-layers.byte-layers) |
| Listes de tâches | ci-dessous |

- [x] lire le titre
- [ ] lire la suite

Un bloc de code ordinaire se copie, sans plus :

```bash
echo "un bloc bash : affiché, copiable, jamais lancé"
```

> Une citation, pour les remarques à part.

## Confirmer

Une section sans vérification se valide d'un clic :

```acknowledge
J'ai lu cette étape
```
