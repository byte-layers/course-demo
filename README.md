# Cours démo — byte_layers

Un cours court qui passe par chaque bloc de [byte_layers](https://marketplace.visualstudio.com/items?itemName=byte-layers.byte-layers) :
lire, lancer une commande, vérifier, indices, solution, quiz. Il sert aux démos, aux tests et à
la validation de bout en bout de la plateforme.

Pour le suivre : installer l'extension byte_layers dans VS Code, puis ouvrir ce dossier (le
cours est dans `.layers/`).
